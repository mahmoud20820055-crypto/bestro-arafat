# بيسترو عرفات · Bistro Arafat

موقع طلبات أونلاين لمطعم بيسترو عرفات (غزة - شارع النصر)، مع لوحة إدارة للمدير.

## شو فيه

**للزبون (بدون تسجيل دخول)**
- المنيو كامل بالأقسام والأسعار، والأصناف اللي إلها خيارات (تشكن/بيف، سندويش/وجبة، أحجام).
- سلة طلبات، توصيل أو استلام من المحل.
- الدفع: تحويل محفظة/بنك مع رفع صورة الإيصال، أو الدفع بالمحل عند الاستلام.
- كوبونات الخصم.
- صفحة تتبع لايف للطلب، وبيقدر يرفع إيصال جديد إذا انرفض الأول.
- «طلباتي»: الطلبات المحفوظة على الجهاز، أو كل الطلبات برقم الجوال ورقم أي طلب سابق. وفيها «اطلب نفس الطلب».

**للمدير (`/admin`)**
- الرئيسية: المبيعات، عدد الطلبات، متوسط الطلب، رسم المبيعات اليومية، والأكثر طلباً (اليوم / 7 أيام / 30 يوم).
- الطلبات: لوحة لايف بتتحدث كل 5 ثواني مع صوت تنبيه للطلب الجديد. تأكيد أو رفض الإيصال، وتغيير الحالة (قبول، تحضير، بالطريق/جاهز، تسليم)، والإلغاء مع سبب.
- المنيو: إضافة وتعديل وحذف الأقسام والأصناف والأسعار والصور، ووضع «خلصان» بكبسة.
- العروض والكوبونات: نسبة أو مبلغ، أقل طلب، عدد استخدامات، تاريخ انتهاء.
- الإعدادات: فتح/تسكير استقبال الطلبات، رسوم التوصيل، أقل طلب، وقت التحضير، أرقام المحافظ، معلومات المطعم، وشريط إعلان.

## التقنيات
Next.js 15 · React 19 · Tailwind CSS · Prisma · PostgreSQL. الصور والإيصالات بتنحفظ بقاعدة البيانات نفسها، فما في داعي لخدمة تخزين إضافية. الإيصالات خاصة وما بيفتحها إلا المدير.

## النشر (مرة وحدة)

1. **قاعدة البيانات:** اعمل مشروع مجاني على [Supabase](https://supabase.com) أو [Neon](https://neon.tech) وخذ رابطين:
   - `DATABASE_URL`: رابط الاتصال المجمّع (pooled). على Supabase بتضيف بآخره `?pgbouncer=true&connection_limit=1`.
   - `DIRECT_URL`: رابط الاتصال المباشر (direct).
2. **ارفع الكود على GitHub.**
3. **Vercel:** اعمل Import للمشروع من GitHub وضيف متغيرات البيئة:
   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | من الخطوة 1 |
   | `DIRECT_URL` | من الخطوة 1 |
   | `SESSION_SECRET` | نص عشوائي طويل، 32 حرف على الأقل |
   | `ADMIN_USERNAME` | اسم مستخدم المدير |
   | `ADMIN_PASSWORD` | كلمة سر قوية للمدير |
4. **جهّز قاعدة البيانات** من جهازك (مرة وحدة)، بعد ما تحط نفس القيم بملف `.env`:
   ```bash
   npm install
   npx prisma db push      # بيعمل الجداول
   npm run db:seed         # بيعبّي المنيو والإعدادات وحساب المدير
   ```
5. **الدومين:** من Vercel → Settings → Domains ضيف الدومين (متل `bistroarafat.com`) واتبع تعليمات الـ DNS.

## التشغيل على جهازك
```bash
cp .env.example .env   # وعبّي القيم
npm install
npx prisma db push && npm run db:seed
npm run dev            # http://localhost:3000  ولوحة المدير على /admin
```

## ملفات الهوية
- الشعار: حط الملف بـ `public/brand/logo.png` (أو `.svg`) وغيّر `LOGO_SRC` بـ `lib/brand.ts`.
- فيديو الواجهة: `public/media/burger.mp4`، وفريمات البرجر اللي بيتركّب مع السكرول: `public/media/frames`.
- صور الأصناف بتنرفع من لوحة المدير ← المنيو ← تعديل.
